# hive-mind-init

Initialize the Hive Mind collective intelligence system.

## Usage
```bash
npx @claude-flow/cli@3.38.12 hive-mind init [options]
```

## Options
- `--force` - Force reinitialize
- `--config <file>` - Configuration file

## Examples
```bash
npx @claude-flow/cli@3.38.12 hive-mind init
npx @claude-flow/cli@3.38.12 hive-mind init --force
```
