# Аватар бота

```bash
node brand/make-avatar.js brand      # перерисовать PNG и SVG
```

Рисуем векторно, а не генератором картинок, по двум причинам: генератор
рисует знак рубля неправильно (лишняя перекладина, не та геометрия) и
оставляет в углу свой водяной знак. На продукте про документы кривой ₽
выглядит плохо.

Знак собран из линий: стойка с чашей — **одним контуром**, иначе на стыке
остаётся заусенец. Перекладина — отдельная линия под чашей.

Лист занимает почти весь круг обрезки: углы отстоят от центра на 456 px при
радиусе круга 512. Аватар чаще всего видят кружком 40 px, там мелочь
не читается — поэтому знак крупный, линии толстые, мелкого текста нет.

Файлы `*-chat.png` показывают, как это выглядит в списке чатов на 120, 64 и
40 пикселях: слева вариант с листом, справа — только знак.

Темы: `gold` (в гамме «Трапезы») и `blue` (нейтральная, для продукта на продажу).
