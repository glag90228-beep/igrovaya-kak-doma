# Рилсы: как мы их делаем

Здесь собрано всё, чему мы научились на вертикальных роликах для двух аккаунтов:
**Первички** и канала **про Claude**. Это и инструкция, и исходники. По ним
следующий ролик собирается без повторения старых ошибок.

Почему папка лежит в Git. Первая версия жила во временной папке облачной
сессии. Контейнер сбросился, и пропала половина работы: 3D-персонаж, звуки,
исходники «Дыр», «Вам должны» и «Платят за 5 секунд». Что смогли, восстановили
из истории разговора. **Правило: всё, что сделано для ролика, сразу кладём сюда
и коммитим.**

## Порядок работы

1. **Сначала узнаём, о чём сейчас говорят, и только потом пишем.** Это правило
   владельца. Ищем через WebSearch: Reddit, Hacker News и Polymarket из облачной
   сессии закрыты. Берём тему, которая обсуждается прямо сейчас (моды Claude
   Code вышли 1 октября, ролик — через три недели).
2. **Каждый факт проверяем по нескольким источникам** и записываем в начало
   сценария вместе с оговорками. Пример — раздел «Факты» в `mody/scenario.md`.
   Цитаты не выдумываем: «назвал их новыми скиллами (по пересказам СМИ)».
3. **Пишем сценарий по формуле** (ниже) с пометками в тексте: `*красный`,
   `+зелёный`, `~акцент`.
4. **Пишем подачу на английском** — теги эмоций перед каждой фразой, для
   ИИ-озвучки. Владелец озвучивает сам и присылает видео со звуком.
5. **Собираем черновик по оценке темпа** (3,8 слова в секунду), снимаем кадры,
   правим, отправляем — чтобы владелец увидел картинку до озвучки.
6. **Голос пришёл — размечаем по паузам** (раздел «Голос»), пересобираем,
   смотрим кадры в местах, где сцена стала длиннее, и заполняем пустоты.
7. **Рендерим и отправляем.** В сообщении пишем, что проверено, а что нет.

## Формула сценария

```
Хук (1–2 с)      острое обвинение зрителю или пугающая цифра
Интрига          «А в конце покажу …, который …»
Разбор           3–5 коротких фактов, у каждого своя картинка
Раскрытие        обещанное из интриги — команда, флаг, скилл
Призыв           «Напиши «СЛОВО» — скину …» (подарок в личку)
Кольцо           последний кадр перетекает в первый — ролик хочется пересмотреть
```

- Хуки, которые сработали: «Слушай, твой проект на нейросети — решето. Его
  взломает любой школьник», «Почти каждый третий видит всё, что ты пишешь»,
  «Claude опять всё забыл? Это не баг».
- Жёсткие слова владелец просил оставлять («решето», «любой школьник»).
  Смягчать их без спроса нельзя.
- Слово-триггер под каждый ролик своё: ДЫРЫ, ПАМЯТЬ, МОДЫ, ТРЕНД, СЧЁТ.
  Обещанный подарок (чек-лист, шаблон) надо реально подготовить.
- Канал про Claude — без Первички. Первичка — только в её роликах.

## Что нельзя

- Выдумывать отзывы и цены (ФЗ «О рекламе», ст. 5). Суммы в кадре помечаем
  «ПРИМЕР», историю — «вымышленная».
- Показывать настоящих клиентов и суммы — только показательные данные.
- Тратить платные сервисы (Higgsfield и подобные) без явного «да» владельца.
- Тянуть картинки с фотостоков в обход сетевых ограничений.

## Подача голоса (English, для ИИ-озвучки)

Перед каждой фразой — 1–2 тега настроения, внутри фразы можно `[pause]`:

```
[conspiratorial][urgent] В Claude Code появились моды — [pause] [low] и почти каждый третий видит всё, что ты пишешь.
[mysterious][quietly] А в конце покажу флаг, который выключает их все за секунду.
[serious][slow] Сообщество проверило триста пятьдесят девять модов: …
[relieved][confident] А если что-то пошло не так — запусти Claude с флагом safe mode: [satisfied] все моды выключатся.
[friendly][upbeat] Напиши «МОДЫ» — скину чек-лист, как проверить мод за минуту.
```

Английские названия пишем так, как их надо произнести: `safe mode`, `last thirty days`.
Текст для озвучки и строки в `build.py` должны совпадать дословно, иначе
разметка голоса не сойдётся.

## Картинка

**Стиль канала про Claude:** тёмный фон `#0F0E0C` с мягким пятном света и
точечной сеткой. Акцент — терракотовый `#D97757`, опасность — `#FF5A4E`,
успех — `#3DDC84`, жёлтый для подсветки слова — `#FFC94D`. Шрифты: Manrope
(заголовки, субтитры) и JetBrains Mono (команды, код). У Первички своя светлая тема.

**Раскладка кадра 1080×1920:**
- заголовок сцены — сверху, `top: 150px`, 84 px, две строки;
- рабочая зона — с 430 до ~1250 px;
- субтитры-караоке — `top: 1450px`, 68 px, по 1–3 слова, слово подсвечивается
  в момент, когда его говорят;
- персонаж — справа внизу (точка `900, 1390`, высота 470 px);
- контент не заходит правее ~760 px, когда персонаж стоит справа.

**Картинки вместо фото.** Фотостоки (Unsplash, Pexels, Pixabay, Wikimedia) из
сессии закрыты. Нашли замену лучше фото: объёмные стикеры **Microsoft Fluent
Emoji** из npm (`@lobehub/fluent-emoji-3d`, `@lobehub/fluent-emoji-anim-1..4`),
лицензия MIT — можно в рекламу. Анимированные (моргающий глаз, «👀», огонь,
молния) режем в спрайт-листы, кадр выбирается от времени таймлайна. Всё
остальное рисуем кодом: окна терминала, чек-листы, рубильник, сетки точек,
счётчики, линии-связи.

**Движение.** Камера в каждой сцене чуть наезжает и резко «бьёт» на ключевом
слове. Секция заголовков `#ttl` стоит вне камеры, иначе при наезде заголовок
обрезается. Вспышка и тряска — только на 2–3 главных ударах за ролик.

## 3D-персонаж

Наш маскот — синий «документ» с загнутым уголком, светящимися глазами-капсулами,
строками текста на корпусе, ножками и тенью. Отрисован кодом на three.js
0.170.0, без моделей и без внешних сервисов. Владелец прислал картинку, а
3D-модель мы сделали сами.

> **Файл `mascot3d.js` утерян вместе с контейнером.** Шаблоны `mody/` и
> `pamyat/` его подключают, поэтому без него рендер не пойдёт: `check.js`
> покажет `makeStage is not defined`. Ниже записано всё, что нужно, чтобы
> собрать его заново с тем же интерфейсом.

**Интерфейс, который ждут шаблоны:**

```js
const ST = makeStage(canvas, { flat: true, dist: 15 });  // холст 1080×1920 на весь кадр
const P = ST.add();          // поза персонажа — обычный объект, его анимирует GSAP
ST.render();                 // вызывается в onUpdate таймлайна
ST.at(px, py)                // → { x, y }: точка экрана в координатах сцены
ST.ppu                       // пикселей на единицу сцены; высота при s=1 — 4.4 * ppu
ST.pointOf(P, поза, 'tip')   // → { x, y } на экране: tip (кончик карандаша), shield, head, bulb
```

**Поля позы:** `yaw`, `spin` (отдельные каналы поворота: покачивание и полный
оборот не должны бороться), `x`, `y`, `jump`, `s` (масштаб, 0 — скрыт),
`rotX/rotY/rotZ`, `sq` (сплющивание), `armL`, `armR` (наружу — плюс, вверх ≈
2.5), `armLx`, `armRx` (вперёд — минус), `handR`, `blink`, `eyeS` (размер глаз,
1.3 — испуг), `happy`, `look`, `mouth`.

**Костюмы (0..1, появляются через масштаб):** `beret` + `pencil` (обычный вид:
берет с усиком-звёздочкой, карандаш в правой руке), `hood` + `glasses` +
`laptop` (хакер: капюшон-арка по форме корпуса, цвет `0x2b3144`, зелёная
подсветка экрана), `doc` (шапочка доктора с крестом), `det` + `mag`
(детектив: клетчатая шапка из CanvasTexture и лупа), `guard` + `flash` +
`beam` (охранник: фуражка с кокардой, фонарик с лучом-конусом, повёрнут почти
на π), `shield` (щит спереди слева), `bulb` + `lit` (лампочка над головой,
свечение `0.2 + 2.4·lit`).

**Стороны:** правая рука (с карандашом) — справа в кадре, левая — слева.
Показать на то, что левее персонажа: `armL: 1.45, armLx: -0.3, rotY: -0.55`.

**Что поняли про персонажа:**
- Холст — на весь кадр, иначе руки обрезаются у края.
- Стоять всё время в одном углу скучно: он должен ходить по кадру и
  переодеваться под смысл сцены. Хакер может появляться с толпой клонов.
- Рот двигается на каждом слове из субтитров (`KW`). Можно двигать и по
  громкости голоса.
- Капюшон-кольцо выглядел нимбом — нужна арка, подогнанная по корпусу.
- Луч фонаря сначала светил в корпус: его надо развернуть почти на π.
- Позы удобно проверять картинками: отрендерить нужные позы в PNG через
  Playwright (`canvas.toDataURL`) и посмотреть на них до сборки ролика.

## Движок сборки

Ролик — это HTML-страница 1080×1920, 30 кадров/с, с одним GSAP-таймлайном. Её
рендерит [HyperFrames](https://hyperframes.dev). Всё анимируется только от
времени таймлайна. Так рендер детерминирован: кадр 412 всегда один и тот же.

**`build.py`** — склеивает текст, тайминг и шаблон:
- `LINES` — фразы с пометками `*` (красный), `+` (зелёный), `~` (акцент);
  слова с `/` или `--` в субтитрах пишутся моноширинным шрифтом;
- без голоса тайминг оценочный: 3,8 слова в секунду, пауза 0,3 с между фразами;
- с голосом — `voice/timing.json`: `{"SEG": [[["кусок фразы", начало, конец], …], …]}`.
  Куски, склеенные через пробел, обязаны дать строку из `LINES` дословно —
  сборка проверяет это;
- `W(i, 'слово')` — время слова в фразе `i`. Из слова выкидываются `«»!?,.:—`
  и ищется начало, поэтому `CLAUDE.md` ищется как `'claudem'`;
- `EV` — именованные события (`EV.sees`, `EV.off`), `EV.s[i]` — начала фраз;
- длина ролика `T` = конец голоса + 1 с (на кольцо);
- пишет `out/index.html` и `events.json` (для звука).

**`template.html`** — сцены и таймлайн. Готовые помощники: `popIn`, `blurIn`,
`blurOut`, `punch`, `shake`, `flash`, `scene(k, от, до)`, `title(k, от, до)`,
`typeIn`, `count` (бегущий счётчик), `line` (SVG-линия), `pose`, `outfit`,
`hopP`, `spinP`, `bubble`, `cam`.

Правила, которые выросли из ошибок:
- элемент, который появляется позже, прячем явно с нуля:
  `tl.set('#term', {autoAlpha: 0}, 0)`, иначе он виден с первого кадра;
- всё, что меняется в сцене, в конце возвращаем в исходное для кольца
  (глаза, пазлы, линии, поле ввода);
- повторы анимаций считаем от длины сцены, а не числом: после озвучки сцены
  становятся длиннее, и фиксированное `repeat: 7` кончается раньше времени;
- уникальность `id` проверяет `build.py`.

**`audio.py`** — бит, эффекты на события из `events.json` и голос из
`voice/voice.wav`. Эффекты нормируются к 0,32 от пика, голос — к 0,95, потом
мягкое ограничение. Генераторы — в `engine/synth.py`.

## Голос: разметка без распознавания речи

Распознавания речи в сессии нет, поэтому режем запись по паузам:

```bash
ffmpeg -i voice.mp4 -vn -ac 1 -ar 44100 -c:a pcm_s16le voice/voice.wav
ffmpeg -i voice.wav -af silencedetect=n=-35dB:d=0.22 -f null - 2>&1 | grep silence_
```

Между паузами — куски речи. Их длины сопоставляем с текстом по скорости:
обычный темп озвучки — 5–7 слогов в секунду. Если вариант раскладки даёт
3,8 или 7+ слогов/с, он неверный. Пример — «Моды»: кусок 43,17–47,61 с —
это вся фраза про `safe mode` целиком (24 слога за 4,4 с = 5,4/с), а не без
«все моды выключатся» (было бы 3,8/с). Самая длинная пауза (0,9 с) оказалась
между фразами, а не внутри. Готовая разметка — `mody/voice/timing.json`.

## Сборка и рендер

```bash
cd trapeza/brand/video/reels
python3 mody/build.py                       # → mody/out/index.html, mody/events.json
bash engine/fetch-assets.sh mody/out        # библиотеки, шрифты, стикеры (один раз)
python3 engine/make-sprites.py mody/out     # нужен Pillow: pip install pillow
cp <mascot3d.js> mody/out/                  # см. раздел про персонажа
python3 mody/audio.py mody/out/audio.wav    # нужен numpy
NODE_PATH=$(npm root -g) node engine/check.js mody/out/index.html
cd mody/out
npx hyperframes snapshot --at 0.5,3.6,12,25,33   # кадры и контакт-лист для проверки
npx hyperframes render --quality high --fps 30 --output ../mody.mp4
```

Рендер 37 секунд занял 4,5 минуты, то есть примерно 7 секунд работы на секунду ролика. Кадры смотрим всегда до рендера, а
готовый ролик — перед отправкой.

## Ошибки и замечания владельца — чтобы не повторять

- Медалька вместо 3D-персонажа — «ты можешь это сам сделать». Сделали в three.js.
- Персонаж стоял в одном углу — однообразно. Нужны костюмы и движение по кадру.
- Убрал жёсткие слова из текста — владелец вернул. Его формулировки не смягчать.
- Отвлёкся на один ролик и забыл обещанные 15-секундные для Первички. Список
  обещанного держим перед глазами.
- Начал писать до исследования — теперь сначала тренды, потом текст.
- Заголовок обрезался камерой — заголовки в отдельной секции вне камеры.
- Счётчик заезжал под заголовок при наезде — тоже вынесли из камеры.
- «Призрак» сцены оставался видимым после смены — прятать всё явно на границе сцены.
- QR в счёте Первички не появлялся — нужен `org.corr_acc` (20 цифр) в данных.
- Ключ `W(2, 'claude.md')` не находился — точка вырезается, ищем `'claudem'`.
- После озвучки сцены растянулись, и экран стоял пустым по 3–4 секунды —
  выводить элементы заранее приглушёнными и «зажигать» на слове.
