# «Моды Claude Code» (аккаунт про Claude) — ~40 с

Формат «Дыр»: острый хук → интрига «в конце покажу» → разбор → раскрытие → призыв.
Живые фото — на фоне ключевых сцен (фото + наш 3D-персонаж + интерфейсные карточки поверх).

## Факты (проверено по нескольким источникам)
- Моды вышли 1 октября 2026, Claude Code 2.1.287; включены по умолчанию. Это плагины на JS/TS внутри Claude Code:
  переписывают промпт до модели, блокируют/меняют вызовы инструментов, меняют интерфейс, добавляют функции.
- Официальная страница для админов (code.claude.com/docs/en/plugins/mods/admin): мод работает с правами пользователя —
  доступ к файлам, процессам и сети; песочница Claude Code моды не покрывает; `--safe-mode` выключает установленные моды;
  совет Anthropic — смотреть код и ставить только от проверенных авторов.
- Ночная проверка списка awesome-claude-code-mods 2 октября (по StashBase): 359 модов, из них 111 видят каждый запрос,
  127 запускают процессы, 95 пишут файлы, 75 ходят в сеть. StashBase оговаривает: это не значит, что моды опасны.
- Сейчас модов тысячи (каталоги показывают 5000+). Создатель Claude Code Борис Черный назвал их «новыми скиллами» (по пересказам СМИ).

## Текст (9 фраз)
1. В Claude Code появились моды — и почти каждый третий видит всё, что ты пишешь.
2. А в конце покажу флаг, который выключает их все за секунду.
3. Моды вышли первого октября. Это маленькие программы, которые меняют самого Claude: интерфейс, промпты, команды.
4. За пару недель их написали тысячи. Создатель Claude Code назвал их новыми скиллами.
5. Сообщество проверило триста пятьдесят девять модов: сто одиннадцать видят каждый твой запрос, семьдесят пять выходят в интернет.
6. Это не значит, что они вредные. Но работают они без песочницы — с твоими правами, файлами и ключами.
7. Поэтому правило простое: ставь моды только от проверенных авторов и смотри код.
8. А если что-то пошло не так — запусти Claude с флагом safe-mode: все моды выключатся.
9. Напиши «МОДЫ» — скину чек-лист, как проверить мод за минуту.
